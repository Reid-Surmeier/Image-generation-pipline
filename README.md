# Motion reference: RISD scan hover turn

A real RISD 3D scan (proton-buddha) rendered in Blender with a locked orthographic camera, turning 0 -> 35 -> 0 degrees about its vertical axis over 5 s at 24 fps, 480x480, on white. Seedance motion reference for risd-godot Issue #110. `render_ref.py` is the exact render script.
